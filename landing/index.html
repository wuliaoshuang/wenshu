THE WORKSHOP

从闪念到成书，不让创作断在工具切换里。

捕风

灵感先落纸

对白、画面、伏笔、修订念头可以先记下，不必立刻整理成完整设定。路上的一句话，回到书房还能接住。

墨小

Agent 构建

不默认乱跑模型。用户手动触发后，墨小会用 Q-Card 追问、确认、生成标题、大纲、人物、细纲和章节。

章节

流式落笔

章节不是一瞬间砸出来，而是逐字出现。DeepSeek Pro 的思考内容显示在气泡顶部，默认折叠。

书房

本地作品库

Agent 沙盒可以显式“采用入库”，进入正式书房。章节、摘要、状态、闪念都在同一套本地存档里。

附件

参考材料进上下文

MD、TXT、DOC、DOCX 可以作为资料喂给当前会话，用来保持世界观、设定文档和历史章节一致。

导出

写完带得走

作品可以导出 Markdown、TXT、JSON。文舒是工坊，不是锁住稿子的仓库。

ROLEPLAY MODE

角色扮演是另一张分页：不规划，不弹卡，只接戏。

打开角色扮演后，它不和 Q-Card 构建流共享消息。AI 角色可以随时切换，“我的角色”是全局身份；对方说话逐字流式输出，导演指令会被理解为镜头、动作、画面和内心调度。

{摄像机视角：}正面到侧面观测，改写角色当前状态，而不是让角色对镜头说话。
{描写画面}扩写场景、动作、光线和距离感，保持角色设定。
{推进剧情}让当前冲突往前走一步，不突然跳场，不替用户决定结局。
[sys] 存档系统级操作不被角色感知，读档后继续扮演。

HOW IT MOVES

创作流程被拆成能反悔的步骤。

  1. 01开一个念头

    从一句话、一张角色卡、一个场景或一段附件开始。

  2. 02选择通道

    要写书就进 Agent 构建；要沉浸互动就开角色扮演。

  3. 03确认后再生成

    标题、大纲、人物、章节都由用户显式触发，不偷偷调用模型。

  4. 04进书房修订

    章节可续写、重写、阅读、导出；闪念和设定也能继续追加。

LOCAL FIRST

你的稿子不该被工具拿走。

文舒没有自建后端。小说、角色卡、会话、API Key、全局提示词和偏好都保存在本机 localStorage。AI 请求由浏览器直连 DeepSeek，费用走你自己的 Key。清掉本地数据，就是彻底清掉。
